# Golden Chance Senior

Landing del proyecto residencial sénior de Golden Chance (norte de España).

- Web estática: `index.html` y `legal.html`, sin dependencias ni proceso de build.
- Bilingüe: español por defecto, inglés con el botón EN o `?lang=en`.
- Formulario conectado a info@goldenchance.es mediante FormSubmit.
- Despliegue en Vercel (`vercel.json` con cabeceras de caché y seguridad).

## Desarrollo local

Abrir la carpeta en VS Code y lanzar Live Server sobre `index.html`.
